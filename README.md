# 🌐 CeresF3b - Personal Website

This repository contains the source code of my personal website, a simple portfolio showcasing my interests and projects.

## ✨ Website Features

- **Minimalist Design**: A simple and clean interface with a dark theme for a better visual experience
- **Interactive Background**: An animated background with particles that react to mouse movement
- **Responsive**: Optimized to work on mobile and desktop devices
- **Projects Section**: Showcases my main projects with links to GitHub repositories

## 🛠️ How It Works

The site is built using standard web technologies:

- **HTML**: Basic page structure
- **CSS**: Styles and animations to make the site appealing
- **JavaScript**: For the interactive particle effect in the background

The interactive background uses the particles.js library that creates a dynamic visual effect. The particles move and react when the user hovers over them or touches the screen on mobile devices.

## 🚀 Featured Projects

- **PowerShell Network Scanner**: A tool for scanning and analyzing network devices
- **PC-Fixer**: Utility for diagnosing and solving common PC problems
- **This website**: The source code of this site

## 👁️ How to View the Site

You can view the site in two ways:

1. **Online**: Visit [CeresF3b.github.io]([https://CeresF3b.github.io](https://ceresf3b.github.io/Ceres.github.io/))

## 🔧 Customization

If you want to use this code as a base for your site:

1. Modify the content in `index.html` to reflect your personal information
2. Update the links to your social profiles and projects
3. Customize colors and style by modifying the CSS rules
